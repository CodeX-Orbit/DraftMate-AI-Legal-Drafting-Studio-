# ⚖️ DraftMate AI — Legal Drafting Studio

**AI-assisted legal drafting and document management workspace built by Team CodeX.**

## 🚀 Overview
DraftMate AI helps lawyers, law students, and legal researchers organize legal documents, prepare drafts, review citations, and manage drafting workflows.

## ✨ Features
- 🔐 User registration and login
- 📝 Legal document drafting assistance
- 📁 Upload and manage legal documents
- ⚖️ Citation review and legal research assistance
- 💾 Save and retrieve drafts
- 📄 Export documents to PDF and DOCX
- 🎙️ Browser-based voice input
- 🗄️ Persistent local storage using SQLite

## 🛠️ Tech Stack
- **Backend:** Python, FastAPI
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Document Processing:** Python libraries

## ⚙️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python run.py
```

Open `http://127.0.0.1:8000` in your browser.
